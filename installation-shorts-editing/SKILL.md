# 티링크 설치 사례 30초 영상 편집

[스토리라인 스킬](../installation-shorts-storyline/SKILL.md)의 `storyboard.json`과 `review.md`를 받는다. 첫 질문을 읽고 마지막 컷에서 **누가 어느 화면을 열어 무엇을 확인하는지** 정한다. 학원·병원·공장 모두 같은 시간표를 사용한다. 업종에 따라 대사, 기능과 실제 UI, 장비, 경로와 외관, 사진, 확인할 업무 행동을 바꾼다.

## 공통 타임라인

세로 1080×1920, 24fps, 30초 무음이 기본이다. 아래 프레임 번호는 0부터 시작하며 각 구간에 끝 번호는 포함되지 않는다. 521프레임 경계는 약 21.708초다.

| 시간 | 프레임 | 화면과 편집 지시 |
| --- | --- | --- |
| 0–3초 | 0–72 | 고객이 현장에서 겪는 고민 한 가지를 묻는다. 첫 프레임부터 업종과 질문이 읽히게 한다. 재구성한 상담은 활용 예시로 표시한다. |
| 3–15초 | 72–360 | 대표가 추천하는 기능과 실제 제품 캡처·녹화를 함께 보여준다. 답변이 가리키는 메뉴, 조작할 버튼, 읽을 기록을 순서대로 확대한다. 영어학원은 통화 요약 → 고객·상담원 키워드 → 원본 통화 재생으로 어떤 안내가 빠졌는지 찾는다. |
| 15–21.708초 | 360–521 | 대표가 현장의 장비를 들고 출발한다. 지도 배경 위에서는 얼굴 배지만 확인된 경로를 따라 움직인다. 입구에서는 같은 장비를 안고 문을 열고 안으로 들어간다. |
| 21.708–25초 | 521–600 | 다음 업무에서 바꿀 행동 한 가지를 대사나 동작으로 보여준다. 학원은 “토요일 10시와 2시, 언제가 편하세요?”처럼 날짜와 시간을 제안한다. 연출한 발화에는 ‘응대 예시’를 붙인다. |
| 25–26.5초 | 600–636 | 실제 설치 사진을 독립된 실사 컷으로 보여준다. 제목에는 공개할 장소나 업종을 적는다. 해당 현장 사진에는 ‘실제 설치 사진’, 별도 현장 자료에는 ‘설치 참고 사진’을 붙인다. |
| 26.5–30초 | 636–720 | 앞부분과 같은 디자인으로 **실제 기능 화면**을 다시 연다. 담당자가 행동 변화를 확인할 메뉴·버튼·기록을 확대하고, 확인 방법 한 문장을 마지막 프레임까지 유지한다. 학원은 ‘상담이력 → 성공통화 이력’의 기간 선택과 재생 버튼에 “다음 상담에서 시간까지 제안했는지 확인해요”를 붙인다. |

병원은 교대 직원이 상담이력에서 변경 요청 시간을 찾는 장면, 공장은 같은 작업 그룹의 실제 무전 화면에서 지시와 복창을 확인하는 장면으로 응용한다. 당일의 예약 확정이나 등록률 변화처럼 해당 화면 밖에서 측정하는 성과는 현장의 별도 기록과 집계 기준이 있을 때만 소개한다.

## 소재 판정과 Higgsfield 컷

- 실제 도입 편은 해당 현장의 확인된 기능·장비와 같은 현장 사진을 사용한다. 공식 제품 캡처는 기능의 근거로, 별도 현장 사진은 참고 자료로 연결한다. 가상 대사와 재구성 장면에 표시를 붙이고, 고객·환자·학생 정보와 사진 식별 정보는 편집 사본에서 가린다.
- 첫 시연과 엔딩의 실제 화면, 사용 가능한 설치 사진, 장비 참조 또는 새 장소의 경로·외관 등 제작에 필요한 자료가 비면 영향을 받는 컷과 필요한 자료를 `needs_input`에 적고 해당 컷의 생성·최종 출력을 보류한다. 확보된 장면의 콘티와 브리프는 계속 정리한다.
- 새로 생성할 컷은 Higgsfield 플러그인에서 만든다. 원본과 같은 귀여운 2D 셀 애니메이션, 대표의 가르마·안경·네이비 재킷, 구도와 비율을 참조한다. 이동 전후에 같은 장비 참조를 쓰고 손이 받치는 위치, 크기, 실루엣이 이어지는지 확인한다. 문을 여는 손은 비워 두고 장비는 대표가 끝까지 들고 들어가게 한다. 생성한 배경에 한글 대사나 제품 UI를 그리지 않고 실사·캡처·자막을 편집 레이어에서 합성한다.
- 기존 이동 클립은 장비·경로·간판·도착지가 이번 사례와 일치할 때 재사용한다. 새 장소는 확인된 출발·도착지로 네이버 지도 경로를 준비하고, 이번 현장의 출발·입장 컷을 연결한다. 지도 제작·영상 사용에 필요한 자료가 아직 없으면 지도를 대기 상태로 둔다. [지도 제작 지침](../tlink-shorts-agent/references/네이버_지도_연동.md)
- Higgsfield에서 해당 컷의 참조 방식, 생성 길이, 비용을 실행 시 확인한다. 실제 설치 사진은 실사 레이어에 둔다. 클립 ID와 참조 소재를 기록하고 사람·장비가 변형된 컷만 교체한다.

## 조립과 검수

1. 자동 편집은 사례별 소재를 연결해 기존 [FFmpeg 실행기](../tlink-shorts-agent/scripts/run_short.py)를 사용한다. 생성 클립이 더 필요하면 같은 실행기의 `--prepare`로 브리프를 만든다. [영어학원 제작 콘티](영어학원_30초_제작콘티.md)의 **등록 상담 편 · 현재 편집본**에 대사와 화면 선택 예시가 있다.
2. 수동 미세 조정이 필요하면 CapCut을 선택한다. 같은 24fps 타임라인에 클립 → 실사·제품 캡처 → 문답·출처·한글 자막 순으로 쌓고 H.264 MP4로 내보낸다. 각 컷에 필요한 조작부만 확대한 뒤 모바일에서 자막 두 줄과 버튼명이 함께 읽히는지 확인한다. 음성을 요청받은 편은 확보된 음성과 자막을 동기화한다.
3. 완성본을 재생해 **첫 15초 안의 고민·기능·실제 화면 → 대표의 장비·지도·입장 → 구체적인 후속 행동 → 설치 사진 → 담당자가 확인하는 실제 화면**의 순서를 점검한다. 600프레임에는 사진의 출처 관계가, 636프레임과 마지막 719프레임에는 실제 제품 UI와 확인 방법이 읽혀야 한다.
4. 공개 자막을 사례 근거와 대조한다. 문답에서 제기한 문제, 담당자의 후속 행동, 마지막 화면에서 확인하는 기록이 서로 연결되는지 확인한다. 현장의 실측값이 없으면 관찰할 수 있는 행동과 확인 방법으로 끝낸다. 콘티, 사진·화면 출처, 생성 클립과 출력 경로, MP4 재생 확인 결과를 실행 기록에 남긴다.
