# 영어학원 도입 사례 숏츠 제작 지침

기준은 팀이 제시한 **티링크 기술적 강점 12가지**다. 각 항목의 번호와 활용 의도를 유지한다. 완성본 길이가 30초인 영어학원 편에서는 고객 질문 하나에 답하는 기능을 중심으로 장면을 배치한다. 이 문서는 팀원이 전달할 프롬프트와 결과물을 검토하는 기준으로도 쓴다.

## 2. 등록률 고민 편 · 15초 문답과 기능 화면

**추천 도입 구성은 티링크 AI 녹취의 전사·요약, STT 키워드 통계, 상담이력 조회·재생이다.** 같은 기간의 고객·상담원 키워드를 나눠 살펴보고, 확인할 통화에서 실제 답변을 듣는다. 이 영상에 넣을 파일과 원본 출처는 [공식 기능 화면 목록](../../../티링크_영어학원_기능화면/화면목록_편집순서.md)에 모았다. [티링크 AI 녹취](https://www.tlinkcrm.com/recording.php)

| 시간 | 녹음 대사 | 편집 화면 |
| --- | --- | --- |
| **0–3초** | **원장** “상담은 많은데, 왜 등록이 안 될까요?” | 원장 클로즈업. 가상 사례면 첫 화면에 표시한다. |
| **3–7초** | **티링크 대표** “AI 녹취로 통화를 글로 바꾸고 요약해요.” | **통화관리 → 파란색 ‘요약’ 버튼**을 확대한다. ‘레벨테스트 일정 문의’는 학원 예시 자막으로 쓴다. |
| **7–11초** | **티링크 대표** “고객과 상담원 키워드를 비교해요.” | **STT 통계**의 고객과 상담원 키워드 영역을 보여준다. ‘레벨테스트·토요일’과 ‘교재·수업 방식’은 가상 데이터다. |
| **11–15초** | **티링크 대표** “이 통화엔 날짜 제안이 없었네요.” | **상담이력 → 성공통화 → 재생 아이콘**을 확대한다. 학부모 ‘토요일에도 테스트 볼 수 있나요?’ / 직원 ‘일정 확인해서 다시 안내드릴게요.’를 예시 자막으로 넣는다. 전체 예시 통화를 검토했다는 설정이다. |

**등록 개선을 보여주는 엔딩.** 상담팀이 실제로 바꾼 안내가 확인되면 **‘레벨테스트 날짜 문의 → 가능한 시간 두 개 제안 → 선택 또는 회신 여부 기록’**처럼 행동을 한 줄로 설명한다. 개선 상담의 예시 대사는 “토요일 오전 10시와 오후 2시 중 언제가 편하세요?”다. 그 아래 별도 카드로 **`학원 등록 기록 기준 · [개선 전 기간] [등록 인원]/[신규 문의 인원] → [개선 후 기간] [등록 인원]/[신규 문의 인원]`**을 보여준다. 예를 들어 상담 후 14일 이내 등록률로 정했다면, 중복 문의자를 제거하고 전후 모두 14일 관찰이 끝난 집단을 비교한다. 비교 자료가 없으면 ‘다음 상담부터 가능한 날짜를 제안하고, 이후 등록 여부를 기록합니다’는 적용 예시를 쓴다. 결과 카드는 학원의 등록 자료와 상담 기록을 연결해 제작한다. [공개 경영분석 보고서의 전환율·표본 기준](https://www.tlinkcrm.com/management.php)

- **30초 팀 편집안**은 0–15초 문답·제품 화면, 15–22초 지도 이동, 22–30초 실사·결과 카드다.
- **35초 팀 편집안**은 0–15초 문답·제품 화면, 15–25초 지도 이동, 25–35초 실사·결과 카드다. 도입 후 업무 변화와 실제 등록률 자료를 모두 읽히게 보여줄 때 이 편집안을 우선 검토한다.
- 제품 화면에는 승인된 가상 상담을 쓰고, 화면 밖 자막에 ‘기능 화면 예시 · 가상 데이터’를 표시한다. 고객과 상담원 키워드는 같은 기간을 사용한다. 요약·키워드 통계는 확인할 상담을 고르는 단서로, 날짜 제안 여부는 개별 통화를 대조해 판단한다.

12개를 주제별 편으로 확장하는 경우 **상담 확인(01·04·05)**, **문의 분석과 교육(02·03·08·09)**, **후속 연락과 등록(06·07)**, **설치와 통합(10·11·12)**으로 이어갈 수 있다.

## 3. 편집 디자인과 팀원 프롬프트 검수

- **화면 구성.** 문답은 발화자를 즉시 구분하고, 기능 설명이 나올 때 해당 제품 화면을 확대한다. 지도는 두 도시 이름과 경로가 읽히게 한다. 지명·기능명·한글 자막은 가능한 한 편집 레이어에서 관리한다.
- **장비와 캐릭터.** 대표자 캐릭터는 팀 참조와 맞춘다. 주 장비는 설치 자료에 맞는 한 종류를 중심으로 보여주고, 이동 중 형태·크기·수량을 유지한다. 구체적인 포트와 배선이 보이면 자료와 대조한다.
- **실사와 기능 화면.** 마지막 실사 구간에는 설치 사진을 우선 읽을 수 있게 두고, 화면이나 요약 카드는 장비를 가리지 않는 위치에 둔다. 학부모·학생의 이름과 번호, 실제 통화 음성은 사용 범위가 확인된 소재로 다룬다. 제품 화면을 재구성할 때는 ‘기능 사용 예시’를 표시한다.
- **음성·자막.** 문답을 소리 내어 읽고 각 구간에 맞춘다. 장비나 설치 조건을 더 설명해야 할 때에는 짧은 화면 라벨을 쓴다. 한글 자막은 두 줄을 기본으로 하고, 무음으로도 질문·답·기능을 이해할 수 있는지 확인한다.

팀원에게서 받으면 **프롬프트 원문과 실제 결과물을 장면별로 나란히** 검토한다. 프롬프트 속 예시 도시나 장비가 최종 컷으로 굳어지기 전에 아래 항목을 대조한다.

| 인계할 항목 | 대조할 내용 |
| --- | --- |
| 장면 ID와 시간, 사용한 프롬프트 원문, 버전 | 선택한 시간표, 대사와 제품 화면의 일치 |
| 모델, 길이, 화면비, 참조 이미지·지도 | 실제 도착 도시, 핀 위치, 대표자 캐릭터, 승인된 장비 형태 |
