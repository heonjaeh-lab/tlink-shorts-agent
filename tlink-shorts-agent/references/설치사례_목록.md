# 티링크 공개 설치처 자료

**확인일 2026년 11월 20일.** 공식 사이트의 설치 갤러리 12건을 공개 순서대로 기록했다. 업종은 공공·복지 2건, 금융 2건, 교육 2건, 의료 3건, 기업 3건이다. 대표 사례는 갤러리의 첫 번째 항목과 같은 현장이다. [티링크 공식 설치 사례](https://www.tlinkcrm.com/case.php)

## 설치 갤러리 12건

표의 `G01`~`G12`는 에이전트가 현장과 근거를 찾기 위한 ID다. 사진은 티링크가 실제 고객 설치 사진으로 공개했다. 갤러리를 참고해 업종이나 녹취 서버 설치 사진의 존재를 확인할 수 있다. 영상 편집에 쓸 사진 파일은 사용이 확인된 자료에서 별도로 연결한다.

**G01에 바로 쓸 수 있는 문장.** 단자함 내부에 녹취 서버를 놓기 어려웠고, 티링크는 벽면 받침대에 서버를 부착한 뒤 단자함 안에는 미러링 스위치만 배치했다. 사진의 두 위치로 설치 결과를 보여줄 수 있다. 해당 현장의 기능 활성화 기록, 상담 내용, 설치일, 대표자 방문, 고객 반응과 성과 수치는 별도 자료가 필요하다. [티링크 대표 사례와 사진](https://www.tlinkcrm.com/case.php)

**G02~G12 보강 항목.** 도착지 도시, 고객 요청, 실제 적용한 기능과 옵션, 장비 모델 및 형태, 설치 위치, 담당자, 사용 결과는 기업 자료나 승인된 사례 메모로 확인한다. 공개명 일부에 지역명이 들어 있어도 동선의 도착지에는 확인된 별도 자료의 도시만 쓴다. 의료 갤러리와 병원 예약 변경 시나리오, 교육 갤러리와 영어학원 시나리오, 기업 갤러리와 다국적 공장 시나리오의 관계는 각각 별도 확인한다.

## 같은 페이지의 별도 구축 실적

이 목록은 설치 갤러리와 별도 이미지에 공개되어 있다. 규모 표기는 해당 이미지 기준이며 `G01`~`G12` 사진을 선택하는 근거로 사용하지 않는다. [티링크 공식 구축 실적](https://www.tlinkcrm.com/case.php)

| 공개 근거 | 해당 기관 |
| --- | --- |
| 100석 구축 실적 | 보험몰 닷컴, 투어익스프레스, 캐럿코리아, 미래아이엔씨, 전주예수병원 |
| 200석 구축 실적 | 아이비즈아카데미 |
| 300석 구축 실적 | 여행박사 |
| 3,000석 구축 실적 | 한국전력 |
| 중앙 녹취 1,000 USER | 세종텔레콤 |
| CTI 구축 및 HCN 공급 표기 | 미라콤 |

**영상에 쓰는 법.** 사례 ID와 제공 자료가 같은 현장이라고 확인되면 실제 설치 사진으로 편집한다. 다른 공개 사진을 사용하기로 했다면 해당 업종의 실제 설치 참고 사진으로 표시하고, 앞에서 설명한 기능이나 성과를 그 사진과 연결하지 않는다. 영상 설명에 필요한 설정이나 기능이 확인되지 않으면 일반 제품 기능을 `활용 예시`로 제시한다.
