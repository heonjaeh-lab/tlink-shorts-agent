# 설치 사례별 지도 컷

첨부한 강일학원 영상에는 사무실에서 학원 입구까지 이어지는 동네 약도가 나온다. 이 사례로 Q&A만 추가할 때는 `map.mode`를 `original_reference`로 두고 제공된 영상의 지도와 타이밍을 유지한다. 새 장소에는 `naver`를 지정하고 그 사례의 출발지와 도착지로 경로를 조회한다. 상호나 영상의 간판을 근거로 실제 소재지를 추정하지 않는다.

## 실행

단독 상품인 NAVER Cloud Maps에서 Directions 5, 도로명 주소를 입력할 때 Geocoding, 네이버 바탕 지도를 쓸 때 Static Map을 Application에 연결한다. 해당 앱의 Key ID와 Key는 실행 프로세스의 환경 변수 `NCP_APIGW_API_KEY_ID`와 `NCP_APIGW_API_KEY`로 공급한다. JSON·프롬프트·영상 파일에는 키를 기록하지 않는다. [Maps 공통 요청 규격](https://api.ncloud-docs.com/docs/application-maps-overview)

`case.json`의 `map` 예시는 아래와 같다. 주소는 공개 청사의 위치를 사용한 예시이며 학원의 소재지를 뜻하지 않는다.

```json
{
  "map": {
    "mode": "naver",
    "origin": {"name": "서울시청", "address": "서울특별시 중구 세종대로 110"},
    "destination": {"name": "부산시청", "address": "부산광역시 연제구 중앙대로 1001"},
    "video_use_basis": ""
  }
}
```

- 지점 자료에 확인된 WGS84 좌표가 있으면 각 주소 대신 `{"name":"현장 공개명","lon":경도,"lat":위도}`를 쓴다. 주소의 검색 결과가 여럿이거나 자동차 경로가 없는 경우 해당 사례의 지점을 다시 확인한다. 좌표가 있는 지점은 Geocoding 호출을 생략한다. [Geocoding](https://api.ncloud-docs.com/docs/application-maps-geocoding) · [Directions 5](https://api.ncloud-docs.com/docs/application-maps-directions5)
- **조회**는 `python3 scripts/naver_route.py case.json`으로 실행한다. 성공하면 `route_verified`를 반환한다. 응답의 주소·좌표·경로를 파일에 보관하지 않는다. 교통 상황에 따라 Directions 경로가 달라질 수 있으므로 화면을 실제 이동 기록으로 설명하지 않는다.
- 신규 지도 상단에는 `origin.name`과 `destination.name`에 입력한 공개 지점명을 그대로 표기한다. 출발·도착 점과 같은 색으로 표시하고, 가까운 지점도 한 안내판에서 읽을 수 있게 배치한다. 안내판은 아래쪽 출처·로고 영역을 피한다.
- **영상**은 `python3 scripts/naver_route.py case.json --badge face.png --seconds 4 --output map-new.mp4`로 만든다. 배경을 고정하고 실제 도로의 꺾임을 따라 청록색 점선을 그린다. 출발·도착에 짧게 머무르며 대표자 얼굴만 이동한다. 원형 배지 PNG는 얼굴 주변을 투명하게 준비한다. 1080×1920, 30fps, 무음 MP4를 새 파일에 기록한다. Pillow와 FFmpeg가 필요하다. 새 사례의 이동 시퀀스에서 지도 컷만 교체하고, 앞뒤에 해당 장소·장비로 제작한 출발 및 입장 컷을 넣는다. [Static Map](https://api.ncloud-docs.com/docs/application-maps-static)
- **원본에 가까운 그림체**가 필요하면 `map.illustration`에 자체 제작한 지도 PNG의 `path`와 `bounds`를 지정한다. `bounds`는 지도 네 변의 WGS84 경도·위도를 `[서, 남, 동, 북]` 순서로 기록한 배열이다. 북쪽이 위인 9:16 Web Mercator 바탕 그림이어야 하며, 지형·도로와 테두리가 같은 지리 범위를 나타내야 한다. 얼굴 배지가 들어갈 여백을 확보한다. 이 경우 Directions 경로를 해당 그림에 투영한다. 좌표 기준이 없는 손그림이나 이전 사례의 경계를 재사용하면 지점이 어긋난다.
- **출처와 사용 범위**. NAVER Cloud Maps 약관 제7조는 서비스 결과의 즉시 사용과 별도 저장·재사용의 범위를 정한다. 받은 지도·경로를 홍보 MP4로 저장·편집해 배포하는 범위를 확인할 수 있는 경우에만 `video_use_basis`에 계약이나 서면 답변의 참조를 적는다. 제공되는 바탕 지도의 출처·로고가 보이는 상태로 편집한다. 사용 범위가 확인되지 않은 실행은 조회에 그치며, 시연에는 팀이 제공한 해당 사례의 기존 이동 영상이나 독립적으로 제작한 지도 클립을 쓸 수 있다.
