# 힉스필드 장면 입력

[강일학원 편집 사례](../examples/강일학원_편집사례.json)를 복사해서 사례별 촬영 지시를 정리한다. 같은 장소에 같은 장비를 든 원본이 있으면 필요한 컷만 생성한다.

[공장 편집 예시](../examples/공장_장소장비_교체예시.json)는 같은 대표 캐릭터를 가상의 물류 공장으로 이동시키는 입력이다. 학원의 넓은 랙을 티링크온 COMPACT 휴대 단말로 바꾸고, 거리와 출입문을 공장에 맞게 각각 지정한다. 두 지도 지점은 변수를 시험하는 예시 좌표다. 실제 작업장 위치와 영상 이용 근거는 입력받아 교체한다. 단말 외형 참조는 티링크 공식 사진이다. [티링크온 제품 라인업](https://www.tlinkcrm.com/tlinkon.php) · [COMPACT 원본](https://www.tlinkcrm.com/images/tlinkon/tlinkon-device-compact.jpg)

| 입력 | 준비할 내용 |
| --- | --- |
| `case_id`, `source_case_id`, `source_clip` | 이번 사례 ID, 원본 영상이 묘사한 사례 ID, 로컬 영상 경로. 새 고객에게는 새 사례 ID를 부여한다. 경로는 사례 JSON 기준이며 원본 영상은 실행 시 `--source`로도 지정할 수 있다. |
| `source_reference_frames` | 원본에서 직접 고른 대표 얼굴·화풍, 장비 식별 컷의 초 위치. `crop_xywh`는 원본 픽셀 위치와 크기다. `source_travel_segments`의 프레임 범위는 시작을 포함하고 끝을 제외한다. 원본을 교체하면 다시 확인한다. |
| `site` | 원본 현장 재사용은 `mode: source`, 다른 현장은 `new`. `interior`에 Q&A 공간, `street`에 달리는 거리, `entrance`에 도착할 외관을 각각 입력한다. `customer_role`은 질문자, `qa_action`은 그 현장에 적합한 응답 동작이다. 실물 외관을 재현하려면 `exterior_image`에 현장 사진을 연결한다. 예시 그림에는 연출한 외관임을 표시한다. |
| `site.sign_mode` | `preserve`는 같은 장소의 원본 간판 픽셀을 유지한다. 새 현장의 승인된 표기는 `overlay`와 `sign_text`로 전달한다. 익명 현장에는 `none`을 쓴다. |
| `hardware` | `source_depiction`은 동일 사례의 가상 영상에 이미 묘사된 소품을 이어 쓸 때 선택한다. 새 실물은 `product_image`와 `reference_image`를 연결하고, `identity`에 확인된 장비 이름, `appearance`에 외관 특징, `grip`에 몸 대비 크기·방향·손 위치를 적는다. 앱만 공급한 실제 구성은 `software_only`와 `action`에 기존 기기 설정 동작을 쓴다. 확인할 실물이 남은 사례는 Q&A부터 준비하고 제품 컷은 자료 확보 뒤 편집한다. |
| `map` | 제공 영상과 같은 지도를 살리는 이번 예시는 `original_reference`다. 새 장소는 `naver`와 `origin`, `destination`을 적는다. 두 지점에 각각 이름과 확인된 주소 또는 경위도를 넣고, 지도 영상의 허용 범위는 `video_use_basis`에 기록한다. 지도 스크립트에 같은 사례 JSON을 전달한다. |
| `qa_beats` | 첫 질문부터 답까지 시작·끝 시간, 화자와 실제 자막 문구를 적는다. `ui_image`는 해당 기능의 공식 화면, `editor_note`는 보여줄 버튼·범위와 데이터의 성격이다. 기능 화면과 고객 대사를 별개 레이어로 보관한다. |

원본 대표는 가르마 있는 검은 머리, 가는 안경테, 남색 재킷, 밝은 셔츠를 입는다. 연필선 같은 짙은 테두리와 따뜻한 벽색, 옅은 하늘색 유리, 절제된 셀 음영을 Q&A 장면에도 적용한다. 장비를 들 때 팔 아래에 잡히는 두께와 질량, 손잡이 위치는 이번 장비 사진을 따른다. 서버랙·휴대형 무전기·스마트폰이 서로 같은 크기의 소품으로 그려지면 해당 컷을 교체한다.

완성 학원 편은 실행 폴더의 `사례.json`을 `run_short.py`에 넘긴다. 이 사례는 장면 대사의 줄바꿈과 타이밍을 `qa_beats`에서 한 번 관리한다. `editing.opening`은 각 큐에 맞는 화면 확대 영역과 예시 표시를, `editing.closing`은 마지막 장면의 자막을 담는다. 공장 예시도 이 편집 구조를 제공한다. `--qa`, `--run`, `--arrival`에 검수한 생성 영상을 연결하고, 얼굴 배지와 허용된 NAVER 경로를 준비해 합성한다. 이번 학원 편의 원본·공식 화면·문답 클립은 사례 파일 기준 `소재/`에 있다.

```sh
python3 scripts/compile_edit_brief.py examples/강일학원_편집사례.json --output 생성_브리프.json
```

출력에서 `shots.qa`, `shots.run`, `shots.arrival`의 `prompt`와 `references`를 해당 컷에만 사용한다. `reuse_source_segment`로 정해진 컷은 원본에서 가져온다. 새 장소에서는 이전 간판이나 장비가 보이지 않도록 대표자 얼굴을 따로 잘라 넣고, 장비 사진·현장 사진은 서로 구분하여 전송한다. `shots.map`은 지도 어댑터나 원본 클립에서 받아 편집한다. 한국어 자막·실제 기능 화면·새 간판의 글씨는 편집에서 합성한다. 간판 정면에 고정 카메라를 쓰면 고정 좌표에 합성할 수 있고, 움직이는 간판에는 해당 평면을 추적한다.

예시 자료의 ‘19인치 랙’은 사용자가 지정한 애니메이션 속 형태다. 강일학원의 주소·설치 기종·AI 옵션·등록률 수치를 입증하는 자료는 별도로 받는다. `mode: real`인 실제 소개는 기존 현장 근거표 검토를 함께 거친다. 기존 사례 형식대로 `evidence`에 자료 ID별 `type`, `case_id`, `source`를 기록하고, `hardware.evidence`에 설치 확인 자료(`installation`), `map.destination.evidence`에 장소 확인 자료(`location`)의 ID 배열을 넣는다. 동일한 `equipment.evidence`와 `destination.evidence`가 기존 사례 입력에 있으면 재사용한다.
