# 영어학원 숏츠 재실행

완성본은 같은 폴더의 `강일학원_30초_완성본.mp4`다. 압축을 푼 최상위 폴더에서 다음 명령으로 포함된 영상과 제품 화면을 다시 편집할 수 있다.

```sh
python3 tlink-shorts-agent/scripts/run_short.py 영어학원_숏츠_실행/사례.json --out-dir 새_출력
```

25–26.5초에 영어학원 편의 설치 참고 사진이 나온다. 26.5–30초에는 티링크 상담이력의 기간 조회와 녹취 재생 화면에서 전후 상담을 다시 듣고 테스트 시간을 제안했는지 확인하는 예시를 보여준다.

준비물은 Python 3.11 이상, Pillow, FFmpeg·FFprobe, 한글 글꼴이다. `새_출력/숏츠.mp4`가 결과다. 사진과 상담 대사를 바꿀 때에는 `사례.json`을 복사해 사용한다. 다른 장소로 이동하는 영상은 스킬의 [장면 입력](../tlink-shorts-agent/references/힉스필드_장면입력.md)과 [지도 연동](../tlink-shorts-agent/references/네이버_지도_연동.md)을 따른다.
